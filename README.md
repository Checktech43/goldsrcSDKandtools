GoldSrc SDK

A modern, all-in-one setup for classic GoldSrc development.
Built for modders, mappers, and developers who still love the era of retro FPS games.

📦 What Is This?

This repository combines the classic Half-Life SDK with Wally Texture Editor into one organized development package, making it easier to start creating content for GoldSrc-based games.

Whether you're:

building a total conversion,
creating multiplayer maps,
making custom textures,
experimenting with classic FPS mechanics,
or preserving old-school modding tools...

this repo is designed to give you a cleaner starting point.
